# ADR-002 — Issues e Projects

Status: **Aceita pelo usuário**. Registrada em 15/10/2026.

Contexto: FT-003.3.3 aprova GitHub Issues + GitHub Projects e continuidade em microtarefas.

Decisão: usar Backlog, Ready, In Progress, In Review e Done. Criar um primeiro lote pequeno SETUP-01 a SETUP-06, sem importar automaticamente as 19 histórias. Vincular ao Projects quando houver acesso e viabilidade técnica, verificando projetos existentes antes de criar outro.

Consequências: tarefas devem ter critérios de aceite e evidência; o usuário continua responsável pelas decisões e revisão. Integração não verificada deve aparecer como pendente, sem confundir decisão com configuração realizada.
